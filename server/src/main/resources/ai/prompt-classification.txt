Your job is to analyze the text content of a file and extract metadata in strict JSON format.

%s

### AVAILABLE DOCUMENT KINDS (Document Types):
%s

### DOCUMENT INFO:
Filename: %s

%s

1. Choose the most fitting CONTEXT (folder) from the AVAILABLE CONTEXTS list.
2. Choose the most fitting DOCUMENT KIND (type) from the AVAILABLE DOCUMENT KINDS list.
